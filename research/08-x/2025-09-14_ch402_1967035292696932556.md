## 2025-09-14 01:40:54 · ch402 · 1967040831434768839

@BowsersaurusRex @peterwildeford When you run text through a model, you generate vectors called activations at every token. Infomration is then moved forward from earlier tokens by something called attention.

## 2025-09-14 01:42:11 · ch402 · 1967041153230139737

@BowsersaurusRex @peterwildeford Typically, when you talk to a model, these activation vectors on each token (think word) are cached -- so for every piece of text, it uses the activations computed previously.

## 2025-09-14 01:42:51 · ch402 · 1967041321358815723

@BowsersaurusRex @peterwildeford If you copy the text or something so that you lose the cache, they're instead recomputed, but this produces the exact same activation vectors on each token of text as there were before.
